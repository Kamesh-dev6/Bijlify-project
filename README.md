# Bijlify Full Home Page — Desktop First

This project expands the supplied desktop hero/navbar into a complete React home page while keeping the same visual language.

## Sections

1. Navbar
2. Hero
3. About Bijlify
4. Charging segments
5. Products
6. Software / consumer app
7. Business starter section
8. Why Bijlify
9. Contact form
10. Footer

## Important

The live Bijlify site is JavaScript-rendered and its current homepage content could not be directly extracted by a text crawler. The section structure and copy in this build therefore use the publicly available Bijlify product/solution information and the navigation you supplied, while keeping your redesigned hero as the visual anchor.

This is intentionally **desktop-first**. Responsive behavior is not the focus yet.

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.
